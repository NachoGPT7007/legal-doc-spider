# 法律文书抓取器

**填一个网页地址 → 自动把页面上的正文（判决书、司法解释、法律条文、法律意见）抓下来 → 存成方便阅读和分享的文件。**

- 不用安装任何第三方库（只用 Python 自带功能）
- 零基础可用：双击 `启动.bat`，填地址或检索词，点开始
- **两种抓法**：
  ① 给一个列表页，跟进它的链接
  ② **按关键词 / 按字段去网站检索，再抓搜到的每一条**（已实测：最高人民法院官网、最高人民法院公报）
- **自动翻页**：自动跟随「更多 / 下一页」，连「更多页自己的分页」也会翻 —— 实测同一入口页，候选链接从 10 个提升到 62 个，抓到 40 篇 / 23.1 万字
- **23 列结构化字段**：案号、文书类型、案件分类（民事/刑事/行政…）、案由、诉讼分类（合同纠纷/离婚纠纷/故意杀人…）、法院名称、法院级别、地区、审判程序、裁判日期 —— 字段体系对齐裁判文书网和北大法宝
- 抓取结果：一张 Excel 索引表 + 每篇一个 txt 全文 + 一份汇编
- 已在真实网站上验证：最高法官网司法解释全文（4323 字 / 67 段）；公报检索「民法典」抓到 37662 字的民法典正文

## 30 秒上手

1. 双击 **`启动.bat`**
2. 在输入框里粘贴网址，例如：
   ```
   https://www.court.gov.cn/fabu.html
   ```
3. 在「只抓链接含」里填（抓司法解释时）：
   ```
   解释,规定,批复,意见
   ```
4. 点 **「开始抓取」**
5. 抓完点 **「打开结果文件夹」**

> 更细的操作、每个参数的含义、抓不到时怎么排查 → 看 **[使用说明.md](使用说明.md)**

## 文件清单：每个文件是干什么的

### 你可以直接用的（不用懂代码）

| 文件 | 作用 |
|---|---|
| **`启动.bat`** | ⭐ 双击我就能打开抓取界面 |
| **`启动.pyw`** | 备用启动方式：不弹黑色命令行窗口，双击直接出界面（黑窗口乱码时用它） |
| `config.ini` | ⭐ 所有可调参数都在这里（抓多少页、间隔几秒、筛选关键词……） |
| `使用说明.md` | 完整操作手册（含常见问题排查） |
| `站点可行性检测报告.md` | 十几个法律网站的实测结果：哪些能抓、哪些抓不到、为什么 |
| `代码注释详解.md` | 分区逐段讲代码原理（想搞懂程序怎么运作就看它） |
| `samples/` | 放你 `Ctrl+S` 保存下来的网页（抓不让自动抓的网站时用） |
| `output/` | 结果就放在这里，每次抓取自动建一个带时间的子文件夹 |

### 程序本身的代码（5 个模块，各管一段）

| 文件 | 职责 | 一句话说明 |
|---|---|---|
| `gui.py` | 界面区 | 画窗口、接你的操作、显示进度 |
| `cli.py` | 命令行区 | 不开窗口的用法，适合批量或定时任务 |
| `spider/fetcher.py` | 抓取区 | 按地址把网页下载回来，并正确识别编码（gb2312/UTF-8） |
| `spider/parser.py` | 解析区 | ⭐ 核心：从一堆 HTML 里找出哪一段才是正文 |
| `spider/cleaner.py` | 清洗区 | 去掉「责任编辑」「ICP备」「上一篇」这类杂质，按关键词筛选 |
| `spider/exporter.py` | 输出区 | 写成 CSV 索引、单篇 txt、JSON、汇编 |
| `spider/crawler.py` | 调度区 | 把上面四个串起来，控制页数、间隔、钻几层 |

**数据流向**：

```
你的网址
   ↓
fetcher（下载 + 解码）
   ↓
parser（找正文）
   ↓
cleaner（去杂质 + 筛选）
   ↓
exporter（写文件）
   ↑
crawler 全程指挥（页数上限 / 每页间隔 / 链接筛选）
```

## 已知边界

| 情况 | 能不能抓 | 出路 |
|---|---|---|
| 政府 / 法院官网的静态页面 | ✅ 能 | — |
| JS 动态渲染的页面（裁判文书网、威科先行、北大法宝、国家法律法规数据库） | ❌ 不能 | 浏览器 `Ctrl+S` 保存 → 用本程序离线解析 |
| 需要登录或付费的内容 | ❌ 不能 | 同上（前提是你自己有权限查看） |

详见 **[站点可行性检测报告.md](站点可行性检测报告.md)**（有 15 个网站的真实实测数据）。

## 使用范围与合规

本工具只做**抓取与结构化**，不改变目标站点的内容与访问规则。使用前请自行确认：

1. **只抓公开信息。** 法院官网、公报发布的司法解释、公告、典型案例属公开政府信息。**裁判文书网等含当事人信息的来源**，抓取与再分发涉及个人信息保护，请自行评估合法性后再用。
2. **遵守目标站点的 robots.txt 与使用条款。** 默认请求间隔 1 秒、不并发；若站点声明禁止抓取，本工具不应被使用。
3. **产出由使用者负责。** 结果里保留「抓取说明.txt」记录来源与时间，再分发时不要删除它。
4. **不采集自然人信息。** 本工具不针对个人做信息收集；若抓到的页面含个人信息，请自行脱敏后再处理。

作者不提供目标站点清单，也不对被抓取站点的条款变化负责。
